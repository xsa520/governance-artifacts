# Samples — Redacted Governance Decisions

## Evidence-status clarification

The samples in this directory were created to illustrate the intended
structure and semantics of governance artifacts.

Their correspondence to specific underlying runtime events has not
been independently re-established from the currently available source
records. They should therefore be treated as illustrative,
provenance-unconfirmed representations rather than independently
verified evidence that enforcement occurred.

This clarification does not assert that the represented events did not
occur. It records only that their underlying provenance is not
currently confirmed.

---

The files in this directory are **redacted narrative representations
of governance decisions**.

They are provided solely to illustrate:
- The intended structure of governance decision artifacts
- How non-overridability was represented
- How discretionary exceptions were represented as absent

These samples:
- Are not recommendations
- Are not configurable examples
- Do not imply optional behavior

Each file illustrates the structure an audit-oriented decision
artifact was intended to take; see the evidence-status clarification
above regarding provenance and verification limits.
